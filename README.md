## ❓ FAQ

**Q: Do I need to run it as Administrator?**  
A: No. These are editable game configuration files and normally require standard user access.

**Q: Can antivirus software block CFG scripts?**  
A: CFG files are plain-text configuration files. Review their contents before copying them into your game folder.

**Q: Does it work on Windows 11?**  
A: The configuration files can be edited and installed on Windows 11. Your game installation and folder location must be accessible.

**Q: Are there separate scripts for all nine classes?**  
A: Yes. The collection is organized around Scout, Soldier, Pyro, Demoman, Heavy, Engineer, Medic, Sniper, and Spy.

**Q: How do I update my scripts?**  
A: Back up your existing CFG files, review the new versions, and replace or merge only the settings you want to change.
